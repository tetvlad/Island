# Island Simulation

Итоговый проект 2 модуля JavaRush University. Это консольная многопоточная симуляция экосистемы острова размером 100х20 клеток, населенного растениями и 15 видами животных.

## ⚙️ Реализованный функционал

- **ООП иерархия:** Создан базовый класс `Animal`, от которого наследуются хищники (`Predator`) и травоядные (`Herbivore`), а от них — конкретные виды (волк, медведь, лиса, заяц, утка и т.д.).
- **Жизненный цикл:** В течение каждого такта животные могут:
    - **Перемещаться** (на заданное количество клеток с учетом границ острова).
    - **Питаться** (вероятность съесть жертву или растение рассчитывается по таблице из ТЗ).
    - **Размножаться** (при наличии пары в одной клетке и соблюдении лимита вместимости).
    - **Умирать** (от голода, если закончилась сытость, или быть съеденными).
- **Многопоточность:**
    - `ScheduledExecutorService` (1 поток) — отвечает за запуск тактов симуляции по расписанию.
    - `ExecutorService` (Пул потоков) — распараллеливает процесс обработки клеток острова.
    - Использованы `CopyOnWriteArrayList` и `ReentrantLock` для предотвращения `ConcurrentModificationException` и дедлоков.
- **Статистика:** На каждом такте в консоль выводится подробная информация о количестве живых растений и животных каждого вида.
